# Adek Studio Academy

A production-focused academy website for Adek Studio Academy in Lagos, Nigeria. It presents onsite and online training, transparent pricing, Digital Marketing details, benefits, FAQs, registration, location, and content-ready trainer and student-success sections.

## Technology

- TanStack Start and React 19
- TypeScript and Vite
- Tailwind CSS pipeline with custom responsive styling
- Netlify Forms
- Lucide icons

## Local development

Install dependencies with `pnpm install`, then run `pnpm dev`. Netlify Form processing becomes active on a deployed Netlify environment.

## Updating content

Edit `src/data/academy.ts` for courses, prices, FAQs, benefits and contact information. Page sections are in `src/routes/index.tsx`. When registration fields change, update both the React form and `public/__forms.html`.
